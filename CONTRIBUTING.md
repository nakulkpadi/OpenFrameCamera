# Contributing

OpenFrame welcomes issues, tested devices, bug fixes, translations, UI improvements, and original camera/image-processing code. Create a branch, describe devices and Android versions, and include before/after performance evidence for camera algorithm changes. Run CI and test cancel, permission, orientation, output URI, and privacy behavior before opening a PR.

**Originality rule:** Do not submit Oplus/OnePlus or any other manufacturer's proprietary code, decompiled sources, DLL/SO libraries, artwork, APK assets, shaders, copied LUTs, or ML models. Use public Android APIs, independently written source, or dependencies with verified redistribution licenses.

**Safety rule:** Do not add telemetry, forced uploads, face-shape alterations for tenant/ID photos, gallery publication by default, or privileged permissions without design/security review.
